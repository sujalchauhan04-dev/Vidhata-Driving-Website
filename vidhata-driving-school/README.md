# Vidhata Driving School

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Deploy to Vercel
```bash
npm install -g vercel
vercel
```
Or push this folder to a GitHub repo and import it at vercel.com — either works.

## Edit content
Open `app/page.tsx`. The `COURSES`, `STEPS`, and `WHY` arrays near the top
hold all the editable text. Phone number and WhatsApp link appear in a few
places — search for `9898748020` to update everywhere at once.

Photos are in `public/car-front.jpg` and `public/car-back.jpg` — replace
with new files of the same name to swap them.
